# Summary

This repository is a collection of standalone react applications that are built and distributed independently.  Each folder contains it's own React application which is in turn deployed as embedded code onto another website.

Each react application represents a tool to support board gaming.  Our list of applications include:

- Heat, Pedal To The Metal
- Ticket to Ride

## Heat, Pedal To The Metal

This application generates a random "Legends" deck for the "Heat, Pedal to the Metal" board game.

Key Facts:

- Code is managed in the `/Heat` folder`
- Build assets are are limited to:
  - heat-legends-generator.css
  - heat-legends-generator.js
- Deployed to: https://www.stott.pro/article/heat-legends-deck-generator
